## Remy Mazmanian

I build technical tooling for fields that mostly run on outdated processes.

Currently: **[WP MCP Connector](https://github.com/remymazmanian/wp-mcp-connector-plugin)**, a self-contained WordPress plugin that serves a site to AI clients over the Model Context Protocol. Streamable HTTP and legacy HTTP+SSE, three auth routes including a built-in OAuth 2.1 server with PKCE, 32 permission-gated tools, and a single call that builds a finished post with images and SEO. GPL-2.0.

My background is in precision systems work — diagnosing and fixing complex technical problems under pressure — and before that, years in professional audio and studio environments, which is where the music tools and presets come from.

The through-line across real estate, finance and music is the same: bring rigorous technical practice into domains that lack it. Tools have to work cleanly, hold up under real use, and remove complexity rather than add to it.
